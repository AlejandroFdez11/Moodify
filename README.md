# Moodify
Clon de Spotify, pero con una nueva función por emociones.

Es una Aplicación web destinada a mi proyecto de final de grado (DAM).
Se trata de una aplicación web creado con React + Vital en el FrondEnd, Node.js para el BackEnd con MongoDB de base de datos.
El objetivo principal de esta aplicación es ser un reproductor de música como lo es Spotify, pero con un nuevo apartado que genera un playlists de canciones según la emoción que sientas en ese preciso instante, para poderle dar una nueva experiencia al Usuario.
